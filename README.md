# 🎮 X0 - Morpion en Dart (CLI)

Un jeu de Morpion (Tic-Tac-Toe) simple et élégant développé en **Dart**, jouable directement dans votre terminal.

---

## ✨ Fonctionnalités

*   **Mode Console** : Une interface texte claire.
*   **Logique de Jeu complète** : Détection des victoires (lignes, colonnes, diagonales) et des matchs nuls.
*   **Architecture Propre** : Code structuré avec séparation des responsabilités (Board, Game, Player).

---

## 🛠️ Stack Technique

*   **Langage** : [Dart](https://dart.dev/)
*   **Interface** : Command Line Interface (CLI)

---

## 🚀 Lancement

### 1. Prérequis
*   Avoir installé le SDK [Dart](https://dart.dev/get-dart).

### 2. Exécuter le jeu
```bash
dart bin/main.dart
```
